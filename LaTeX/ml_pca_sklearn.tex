\begin{frame}[fragile]
\frametitle{Principal Component Analysis (Recap)}
\begin{itemize}
	\item Scikit-learn has methods to compute PCA and several variants. 
	\item Classic PCA (\texttt{sklearn.decomposition.PCA}) computes a full singular value decomposition (SVD) of the centered data
	\begin{itemize}
	\item The cost grows as
	$\mathcal{O}(n_{\max}^2 \cdot n_{\min})$, where $n_{\max}$ and $n_{\min}$ are the larger and the smaller of the number of samples and the number of features
	\item For large data sets like the current one, the fit can be slow
	\end{itemize} 
\end{itemize}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{Alternate method}

\begin{itemize}
\item Fortunately, Scikit-learn has an alternative method that is much faster.
\begin{itemize}
\item Cost: $\mathcal{O}(n_{\max}^2 \cdot k)$ for $k$ components, instead of $\mathcal{O}(n_{\max}^2 \cdot n_{\min})$
\end{itemize} 
\item The speed comes at a price: it is based on random projections, so the results are not as robust as the normal method. 
\item But for tasks such as ours where we are seeking only a few of a large number of eigen-vectors, it performs fairly well. 
\item To keep our results consistent between runs, we'll explicitly set the random seed for the fit. 
\item You should repeat this with several different random seeds to convince yourself that the results are consistent:
\end{itemize}
\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{Alternate method}

Linear dimensional reduction using \textit{Singular Value Decomposition} of the data and keeping only the most significant singular vectors to project the data to a lower dimensional space.

\begin{lstlisting}
from sklearn.decomposition import PCA

rpca = PCA(n_components=4, svd_solver='randomized', random_state=0)

X_proj = rpca.fit_transform(X)

X_proj.shape
(4000, 4)
\end{lstlisting}


\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{PCA: Stubs}
After normalizing each feature, the output is simply the singular value decomposition of the covariance matrix of the data.
\begin{lstlisting}
def pca(X):
    # normalize each feature: subtract its mean, divide by its standard deviation
    X = (X - X.mean(axis=0)) / X.std(axis=0)

    # compute the covariance matrix
    cov = (X.T @ X) / X.shape[0]

    # perform SVD
    U, S, V = np.linalg.svd(cov)

    return U, S, V
\end{lstlisting}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{PCA: Exercise}
The first column of \texttt{U} is the first principal component: here the diagonal, with equal weight on both features. It keeps 86.8\% of the variance ($1.736 / (1.736 + 0.264)$).
\begin{lstlisting}
>>> U, S, V = pca(X)
>>> print(U)
[[-0.70710678 -0.70710678]
 [-0.70710678  0.70710678]]
>>> print(S)
[1.73553038 0.26446962]
\end{lstlisting}
\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{PCA: Exercise}
Now that we have the principal components (matrix U), we can use these to project the normalized data into a lower-dimensional space.
\begin{lstlisting}
def project_data(X, U, k):
    U_reduced = U[:,:k]
    return np.dot(X, U_reduced)

# the same per-feature normalization that pca() applied
X_norm = (X - X.mean(axis=0)) / X.std(axis=0)
Z = project_data(X_norm, U, 1)
\end{lstlisting}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{PCA: Exercise}
We can also attempt to recover the original data by reversing the steps we took to project it, including the normalization.
\begin{lstlisting}
def recover_data(Z, U, k):
    U_reduced = U[:,:k]
    return np.dot(Z, U_reduced.T)

X_recovered = recover_data(Z, U, 1) * X.std(axis=0) + X.mean(axis=0)
fig, ax = plt.subplots(figsize=(12,8))
ax.scatter(X_recovered[:, 0], X_recovered[:, 1])
\end{lstlisting}
\end{frame}

\item Notice that the projection axis for the first principal component was basically a diagonal line through the data set.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{Quick Check: PCA}
\begin{block}{Think About It}
In the ``from scratch'' exercise, projecting down to just the first principal component and
reconstructing produced points that all fall on a single diagonal line, losing the spread
around it. What determines how much information is lost this way, and how would you decide
how many components $k$ to keep on a real dataset?
\end{block}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{Quick Check: PCA}
\begin{block}{Answer}
The information lost is exactly the variance captured by the components you dropped: here,
everything along the discarded second eigenvector's direction. In practice you'd look at the
eigenvalues (or scikit-learn's \texttt{explained\_variance\_ratio\_}) and choose $k$ large
enough that the retained components explain a satisfactory fraction (e.g., 90-95\%) of the
total variance, rather than picking $k$ arbitrarily.
\end{block}
\end{frame}
