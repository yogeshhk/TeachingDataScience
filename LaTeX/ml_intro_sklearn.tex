\begin{frame}[fragile]\frametitle{Sklearn Paradigm}
Scikit-Learn provides an object-oriented interface centered around the concept of an Estimator.
\begin{itemize}
\item An Estimator is any object that learns something from data.
\item Classifiers, regressors, clusterers and preprocessors are all Estimators.
\item Every Estimator learns through the same method, \texttt{fit()}.
\item Models then predict with \texttt{predict()}, preprocessors transform with \texttt{transform()}.
\item Swapping one algorithm for another changes one line, not the whole script.
\end{itemize}

\begin{block}{Intuition}
Every appliance in your house does a different job, but they all accept the same wall socket, so you never relearn the plug. In Scikit-Learn that socket is \texttt{fit}/\texttt{predict}. Learn it once and every algorithm in the library is already familiar.
\end{block}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{Scikit-Learn's Estimator API}
The steps in using the Scikit-Learn estimator API are as follows
\begin{itemize}
\item Choose a class of model by importing the appropriate estimator class from Scikit-Learn.
\item Choose model hyper-parameters by instantiating this class.
\item Arrange data into a features matrix and target vector.
\item Fit the model to your data by calling the fit() method of the model instance.
\begin{itemize}
    \item For supervised learning, predict labels for unknown data using the predict().
    \item For unsupervised learning, transform or infer properties of the data using transform() or predict().
\end{itemize}
\end{itemize}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{Estimator}

\begin{itemize}
\item \texttt{fit(X, y)} sets the state of the estimator from the training data.
\item X is the feature matrix, a 2D numpy array of shape (n\_samples, n\_features).
\item y is the target vector, a 1D array of shape (n\_samples,) holding the responses.
\item \texttt{predict(X)} returns the predicted class or value.

\begin{frame}[fragile]\frametitle{Quick Check: The Estimator API}
\begin{block}{Think About It}
A \texttt{StandardScaler} and a \texttt{LogisticRegression} are both Estimators, and both learn from the training data through \texttt{fit()}. Yet only one of them is later called with \texttt{predict()}. Which one is it, and what does the other one give you instead?
\end{block}
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{frame}[fragile]\frametitle{Quick Check: The Estimator API}
\begin{block}{Answer}
Only \texttt{LogisticRegression} predicts, because it is a model: it learns a mapping from features to a target, so \texttt{predict(X)} returns an answer. \texttt{StandardScaler} is a preprocessor: it learns the mean and standard deviation of each column, so it offers \texttt{transform(X)}, which returns reshaped data rather than an answer. This is the whole Estimator API in one line: everything learns with \texttt{fit}, models then \texttt{predict}, preprocessors then \texttt{transform}.
\end{block}
\end{frame}

\begin{frame}[fragile]\frametitle{Logistic Regression: Estimator API in Action}
A concrete run of the \texttt{fit}/\texttt{predict} pattern from the Estimator API, this time on a real classifier with a train/test split.
\begin{lstlisting}
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42)

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)          # learn from training data

y_pred = model.predict(X_test)       # predict on unseen data
accuracy = (y_pred == y_test).mean()
print("Accuracy:", accuracy)

# Output:
# Accuracy: 1.0
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]\frametitle{Putting It Together: Pipeline}

	\begin{itemize}
	\item Scaling the whole dataset before splitting it leaks test information into training.
	\item A \texttt{Pipeline} chains preprocessing and model into one Estimator.
	\item It exposes the same \texttt{fit} and \texttt{predict} methods as any single model.
	\item Inside cross validation, the scaler is refitted on each training fold only.
	\end{itemize}

\begin{lstlisting}
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

pipe = make_pipeline(StandardScaler(),
                     LogisticRegression(max_iter=1000))

# scaler is fitted per fold, never on the held-out data
pipe.fit(X, y)
predictions = pipe.predict(X)
\end{lstlisting}
\end{frame}
