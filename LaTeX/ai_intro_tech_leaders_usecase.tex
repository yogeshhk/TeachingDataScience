\begin{frame}[fragile]\frametitle{AI Opportunity Areas for GTC Teams}
Use this map to identify your highest-value AI opportunities:
\begin{itemize}
\item \textbf{Dev:} Code completion, refactoring, doc generation, code review, security scan
\item \textbf{QA:} Test case generation, test prioritization, bug triage, flaky test analysis
\item \textbf{AppOps:} Runbook assistant, anomaly detection, alert triage, capacity forecasting
\item \textbf{Support:} Ticket classification, auto-response drafting, knowledge base Q\&A, escalation prediction
\item \textbf{Data / Ingestion / Monitoring:} Data quality checks, pipeline failure diagnosis, schema inference, anomaly detection
\end{itemize}
\textbf{Workshop format:} Each group picks one area, drafts: (1) Problem statement (2) Current pain (3) AI-assisted future state (4) Success metric
\end{frame}

\begin{frame}[fragile]\frametitle{Use Case Template}
\textbf{Fill this in for your area:}
\begin{itemize}
\item \textbf{Problem Statement:} (1 sentence, what is broken today?)
\item \textbf{Current Pain:} (quantify if possible, hours/week, error rate, MTTR)
\item \textbf{AI-Assisted Future State:} (what does the workflow look like with AI?)
\item \textbf{AI Approach:} Chatbot? RAG? Agent? Fine-tuned model?
\item \textbf{Data Needed:} What documents, logs, tickets, or code does the AI need access to?
\item \textbf{Success Metric:} How will you measure if it worked? (e.g., 40\% reduction in triage time)
\item \textbf{Risk/Constraint:} Data privacy concern? Need human in loop? Hallucination risk?
\end{itemize}
\end{frame}
