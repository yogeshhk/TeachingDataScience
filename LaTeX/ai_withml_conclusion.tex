\begin{frame}[fragile]\frametitle{AI and ML, Together}
\begin{itemize}
\item AI is the broader goal: building systems that act intelligently.
\item ML is the primary way we get there today: learning patterns from data instead of hand-coding every rule.
\item The concepts covered here, from how AI systems reason to how ML models learn, are two views of the same underlying shift.
\item The real-world examples in the Applications section (healthcare, finance, agriculture, and more) are proof this shift is already well underway.
\end{itemize}
\end{frame}

\begin{frame}[fragile]\frametitle{What's Next?}
\begin{itemize}
\item Pick one domain from the Applications section closest to your own work.
\item Start small: try an existing AI tool on a real task you already do.
\item Once comfortable, explore the basics of a core ML algorithm (e.g. Decision Trees or Linear Regression) to see what is happening under the hood.
\item AI is moving fast; staying curious and hands-on is the best way to keep up.
\end{itemize}
