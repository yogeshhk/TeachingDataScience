# DBpedia: Neural Extraction Framework (GSoC 2024)

Material from the Google Summer of Code 2024 project "Towards a Neural Extraction Framework" for
DBpedia, which aims to improve structured-data extraction from Wikipedia with machine learning. The
framework itself lives upstream at
[dbpedia/neural-extraction-framework](https://github.com/dbpedia/neural-extraction-framework); this
folder holds two teaching files only.

| File | Purpose |
|---|---|
| `clustering_with_predicate_suggestion.py` | Clustering with predicate suggestion script |
| `dbpedia_Week_3_2_SPARQL_DBpedia.ipynb` | Notebook on querying DBpedia with SPARQL |

There is no `environment.yml` here; the files are read-and-adapt examples.
