## Follow-up: technology-currency purge (2026-08-30, later same day)

Per explicit user request ("be aggressive... see which technologies are not much used... let's
purge them"), a second background sweep assessed the remaining `Code/` folders for technology
currency/relevance (not deck linkage, already covered), using actual imports/pinned versions as
evidence. Findings reviewed with the user one by one:

- **Deleted `Code/ludwig/`** (116MB): environment frozen ~2.5 years stale, pinning a pre-release
  `transformers==4.36.0.dev0` and `torchtext==0.16.1` (torchtext was officially discontinued by
  the PyTorch team in Sept 2023).
- **Deleted `Code/meta_bAbi_tasks/`** (113K): its only real script used pre-0.1 LangChain
  (`from langchain.llms import OpenAI`, the removed `.run()` API), no updated sibling existed.
- **Kept `Code/nlp/` and `Code/dnlp/`** as-is: pre-transformer approaches (Doc2Vec, BiLSTM-CRF)
  plus some likely-broken Twitter-API-dependent notebooks, but the user judged this foundational
  teaching material worth keeping rather than trimming.
- **Fixed 3 individual files** with deprecated/relocated APIs, inside otherwise-current folders
  (not folder-level purges):
  - `Code/langchain/langchain_helloworld.py`: pre-0.1 `langchain.llms.OpenAI`/`LLMChain`/`.run()`
    replaced with the repo's current LCEL pattern (`ChatGroq` + `ChatPromptTemplate` +
    `StrOutputParser`, piped and `.invoke()`d), matching the style already used in this folder's
    `langchain_v1_*.py` files.
  - `Code/agents/langchain_camel_agent.py`: `langchain.chat_models.ChatVertexAI` (removed from
    core `langchain` after that class moved to the separate `langchain-google-vertexai` partner
    package) repointed to `langchain_google_vertexai`; `langchain.schema`/`langchain.prompts.chat`
    repointed to `langchain_core.messages`/`langchain_core.prompts`; `self.model(messages)`
    (deprecated direct-call) updated to `self.model.invoke(messages)`. Added
    `langchain-google-vertexai` and `streamlit` (imported but not previously declared) to
    `Code/agents/environment.yml`.
  - `Code/orgpedia/questgen_huggingface.py`: the old monolithic `llama_index` package (pre-0.10)
    with `ServiceContext`/`LLMPredictor`/`LangchainEmbedding` rewritten to the current
    `llama_index.core` namespace with global `Settings` config and native
    `HuggingFaceInferenceAPI`/`HuggingFaceEmbedding`. Also dropped 4 dead imports (`Tool`,
    `ConversationBufferMemory`, `ChatOpenAI`, `initialize_agent`) that were never actually used
    anywhere in the script, one of which (`langchain import HuggingFaceHub`) would also have
    failed against current LangChain had it been left in.
- **Stale catalog cleanup, found while removing `ludwig/`/`meta_bAbi_tasks/`**: `Code/README.md`,
  `CLAUDE.md`'s subdirectory map, and root `README.md` all still referenced one or both. While
  fixing these, also found and fixed two catalog entries that had survived earlier deletions
  undetected: `CLAUDE.md`'s "LLM Fine-tuning" row still listed `gemma/` (deleted this same
  session, in the `/upgrade-repo-tech` pass above) and its "Indic Language" row still listed
  `pritamMarathi/` (deleted even earlier the same session, in the `Code/` folder-by-folder audit).
